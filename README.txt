LAHD Borrower Portal — v94 publishing package

Upload all five HTML files to the SAME folder on your web server.
Open index.html for the first-time / returning-user entry page.

Direct URLs:
- borrower-portal.html — external-facing tiered borrower dashboard (demo defaults to Primary; role switch available)
- staff-dashboard.html — staff Analyst Requests Workspace
- loan-portfolio-transactions.html — borrower request workspace with transaction type preselected where available
- reserve-withdrawal.html — borrower request workspace with reserve withdrawal type preselected where available

These are front-end mockup entry URLs, not separately authenticated production applications.
Production deployment must enforce permissions server-side. Existing internal demo navigation and sample data are retained.
